# CampusService

University technical issue reporting and processing system.

## Project description

CampusService is an information system for receiving and processing technical issue reports at the university.

The system is intended to collect reports about:
- computer problems;
- internet and network problems;
- projector problems.

## Users

- Student / Teacher — creates a technical issue report.
- IT Specialist — processes and resolves the issue.
- Administrator — assigns responsible specialists and monitors requests.

## MVP

The first version of the system will include:
- user authentication and roles;
- creation of a technical issue report;
- classroom and issue type selection;
- assignment of a responsible specialist;
- request status management;
- comments and status history;
- notifications;
- basic reports.
